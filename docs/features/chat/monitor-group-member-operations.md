# 群成员行为监控

> 按群管理白名单监控群成员的进退群与修改群昵称行为

## 类别

聊天 → 群管理（子开关）

## 类型

可开关（在「群管理」设置对话框内）

## 监控范围

仅「群管理」配置的群聊白名单内的群:

- 白名单为空 → 不监控任何群（与群管理处置逻辑一致）
- 白名单非空 → 只监控名单内的群聊

## 描述

监控白名单群组的成员变动, 当检测到以下行为时自动在群聊中发送微信 AppMsg 图文卡片
（标题 + 昵称/ID 字段 + 右侧成员头像, 点击卡片打开该成员头像）:

1. **成员进群** — 发送「进群通知」卡片, 字段两行: 进群昵称、ID
2. **成员退群** — 发送「退群通知」卡片, 字段两行: 退群昵称、ID
3. **成员修改群昵称** — 发送「改名提醒」卡片: 成员、原昵称 → 新昵称

卡片头像是必要组成: 头像拉取失败或发送异常时不发送, 仅记日志（无图片卡/文本回退）。

## 使用方法

在模块设置的「聊天 → 群管理」中打开配置对话框, 在「群成员行为监控」一节启用。

从旧版本升级时, 若原先已启用独立开关, 会自动迁移为开启状态。
