# 群成员行为监控

> 按群管理白名单监控群成员的进退群与修改群昵称行为

## 类别

聊天 → 群管理（子开关）

## 类型

可开关（在「群管理」设置对话框内）

## 监控范围

仅「群管理」配置的群聊白名单内的群:

- 白名单为空 → 不监控任何群（与群管理处置逻辑一致）
- 白名单非空 → 只监控名单内的群聊

## 描述

监控白名单群组的成员变动, 当检测到以下行为时自动在群聊中发送系统消息:

1. **成员进群** — 检测到新成员加入时发送进群卡片
2. **成员退群** — 检测到群成员数量减少时, 在群聊中插入一条系统消息, 显示退群成员的昵称和微信号, 并可点击跳转到该成员的主页
3. **成员修改群昵称** — 检测到群成员的群内昵称 (群备注) 发生变化时, 显示**旧名称 → 新名称**

消息内容以可点击链接形式显示进群/退群/改名的成员, 点击可查看该成员的个人主页。

## 使用方法

在模块设置的「聊天 → 群管理」中打开配置对话框, 在「群成员行为监控」一节启用。

从旧版本升级时, 若原先已启用独立开关, 会自动迁移为开启状态。
