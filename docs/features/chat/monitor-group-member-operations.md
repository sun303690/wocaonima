# 群成员行为监控

> 监控群成员的退群与修改群昵称行为

## 类别

聊天 → 群管理（子开关）

## 类型

可开关（在「群管理」设置对话框内）

## 描述

监控所在群组的成员变动, 当检测到以下行为时自动在群聊中发送系统消息:

1. **成员退群** — 检测到群成员数量减少时, 在群聊中插入一条系统消息, 显示退群成员的昵称和微信号, 并可点击跳转到该成员的主页
2. **成员进群** — 检测到新成员加入时发送进群卡片
3. **成员修改群昵称** — 检测到群成员的群内昵称 (群备注) 发生变化时, 自动记录变更

消息内容以可点击链接形式显示进群/退群/改名的成员, 点击可查看该成员的个人主页。

## 使用方法

在模块设置的「聊天 → 群管理」中打开配置对话框, 在「群成员行为监控」一节启用。

从旧版本升级时, 若原先已启用独立开关, 会自动迁移为开启状态。
