# 消息转圈

> 将一些简单的消息转发到朋友圈

## 类别

朋友圈

## 类型

可开关

## 描述

在聊天消息的长按菜单中添加「转圈」菜单项, 支持将以下类型的消息快速转发到朋友圈:

- **文本消息**: 将文字内容发送至朋友圈
- **引用消息**: 提取引用中的文字发送至朋友圈
- **图片消息**: 将图片发送至朋友圈
- **视频消息**: 将视频发送至朋友圈

## 使用方法

在模块设置中启用后, 长按聊天中的文本、图片或视频消息, 选择「转圈」即可进入朋友圈发布界面

## 媒体转发行为

- **图片**: 转发前自动等待图片下载完成并解密 (聊天图是加密 .dat), 然后以解密后的文件预填到
  朋友圈编辑器; 未加载/解密失败会提示先在聊天里点开加载
- **视频**: 取本地已缓存的 mp4 (需先在聊天里点开过视频), 走**相册流程**打开朋友圈编辑器——
  与"从相册选视频"一致, 支持长视频和封面编辑 (不走 30 秒小视频入口); 本地没有视频文件时
  提示先点开加载
- **多选**: 多条文本拼接为一段文字; 多张图片合并为一条图文朋友圈 (上限同微信); 视频不支持
  与图片混合, 且一条朋友圈最多一个视频
